# ATM System 💳

A simple and user-friendly **ATM System** built using HTML, CSS, and JavaScript.

This project simulates basic ATM operations through a clean and interactive interface.

## ✨ Features

- 💰 Check account balance
- 💵 Deposit money
- 💸 Withdraw money
- 🔐 Simple PIN-based access
- 📱 Responsive and user-friendly interface
- ⚡ Interactive functionality using JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootsrap
- Jquery
- JavaScript
